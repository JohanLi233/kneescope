# Papers & Research Notes

This repository (`kneescope`) ships with the companion paper and the
supporting research notes that motivated and built it. All of this material
originated in the `Viby-Model` research branch and was moved here so it can
live next to the tool that implements it.

### Provenance / external paths

The paper was written inside the `Viby-Model` repo, so a handful of
paths in the text still point at `Viby-Model` artifacts that are **not**
included here:

- `research_runs/probe_*` — training runs and their dumps (`probe_p18_snap`,
  `probe_p30_latesnap`, gap/dense queue ledgers).
- `experiments/*.py` — figure and analysis scripts: `paper_figs.py`,
  `mp_fit.py`, `sigma_upper.py`, `sigma_upper_from_txt.py`.
- `trainer/snapshot.py`, `trainer/muon.py` — the capturing adapter and the
  Muon schedule implementation under study.

Those live in the `Viby-Model` repository. `kneescope` provides the
companion measurement tool (`src/kneescope/`) and the synthetic-validation
tests (`tests/`) referenced in the paper's §Reproducibility.

## Rebuilding the PDF

From this directory (`papers/the_persistence_boundary/`):

```bash
python3 make_tex.py                                   # PAPER.md -> .PAPER_clean.md
pandoc -f markdown+tex_math_single_backslash .PAPER_clean.md \
    -o PAPER.tex -s --shift-heading-level-by=-1 \
    -V geometry:margin=1in -V colorlinks=true -V linkcolor=blue -V urlcolor=blue
sed -i '' 's/\\{\\}/{}/g' PAPER.tex
tectonic PAPER.tex                                    # -> PAPER.pdf
```

> The paper's figures were rendered from raw training logs via
> `experiments/paper_figs.py` in the originating repo; they are committed
> here as-is (`.png` + `.pdf`) and are not regenerated by `make_tex.py`.
